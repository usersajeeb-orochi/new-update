NAB Tab Reporter (optional, makes paper detection use the real page URL)
1. Chrome/Edge -> chrome://extensions -> turn on Developer mode
2. "Load unpacked" -> choose this NAB_TabReporter folder
3. Done. Keep NAB running; no other setup. (Works alongside your existing NAB extension.)
Without it, NAB tries to read the address bar itself if `pip install uiautomation` is present.
